# Box For Root network-state compatibility patch

This branch preserves the hardened `net.inotify` handler validated on the
maintainer's rooted HyperOS device. It is intentionally separate from the
Millet Guard release path: Millet Guard does **not** overwrite third-party Box
For Root scripts automatically.

The patch addresses stale `net.heal.lock` recovery and restart-event feedback.
Its loop-breaking order is:

1. acquire the PID/start-time lock;
2. debounce and resample the network;
3. commit the stable network signature;
4. refresh local anti-loop rules if the signature changed;
5. restart Box at most once for that new signature.

Events generated by that restart then observe the already-committed signature
and become no-ops instead of recursively restarting Box.

For factory-reset recovery, installation, verification and rollback, use
`README_zh-CN.md`. The helper scripts are deliberately conservative: they back
up the original Box handler/state, validate with Android `/system/bin/sh`, and
restore the backup automatically if the controlled Box restart fails.
