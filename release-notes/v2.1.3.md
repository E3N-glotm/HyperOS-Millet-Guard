## Millet Guard v2.1.3

This release fixes a real four-hour FCM outage observed on HyperOS/Android 16 after `ERR_HEARTBEAT_ACK_TIMEOUT`.

### Fixed
- Re-checks `GcmService` immediately after the proactive native MCS heartbeat.
- If the heartbeat exposes a half-open/stale MCS session and changes the service to disconnected, the guard now enters the existing recovery path instead of clearing outage state and exiting.
- Supports newer Google Play services builds where `GcmService` is hosted by the main `com.google.android.gms` process rather than `com.google.android.gms.persistent`.
- Keeps the existing persistent-process path as first choice and uses the main process only as a compatibility fallback.
- Recovery logging now refers to the selected GMS host process rather than assuming `gms.persistent`.

### Device incident validated on 2026-09-29
- Diagnostics reported `ERR_HEARTBEAT_ACK_TIMEOUT` and approximately four hours of FCM disconnection.
- Millet Guard had already logged `proactive heartbeat left GcmService state=disconnected` at 04:45:07, proving the stale connection was detected.
- The old v2.1.2 connected branch then discarded the transition instead of entering recovery.
- The affected device had no `com.google.android.gms.persistent` process; `GcmService` was hosted by `com.google.android.gms`.
- After the live fix, `GcmService` reported `Is client connected: true` and an established `mtalk.google.com:5228` TCP session was present.
- The existing UID-scoped Box FCM bypass remained intact; this incident was not caused by a missing proxy bypass or FCM token reset.

### Regression coverage
- Verifies the heartbeat result is re-read before healthy-state cleanup.
- Verifies a heartbeat-discovered disconnect enters recovery.
- Verifies the modern `com.google.android.gms` process fallback remains present.
- Existing DNS, reconnect-scheduler, xtables, scope, and stale-lock regressions remain enabled.

No FCM token rewrite, new Android alarm, wakelock, blanket GMS proxy bypass, or routine Play services restart is introduced.
