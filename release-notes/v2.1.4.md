# Millet Guard v2.1.4 — Cross-ROM capability audit

- Existing policy engine was already independent of the Android/HyperOS incremental build. There is **no SDK or ROM string whitelist to remove**.
- Added a **read-only** Magisk Action capability report for Settings.System, DeviceIdle, the OEM Greeze service and MCS port visibility.
- When the OEM Greeze dump is unavailable, diagnostics report it honestly instead of guessing that the hook is working.
- No change to FCM connection monitoring, Google/WeChat allowlists, watcher timing, package state, or push-token registration; existing user-managed settings are preserved.
- This Release can operate on different ROM versions when the necessary actual system services exist. A reported interface does **not** prove end-to-end push delivery.
- Compatibility tests: shell syntax, reconcile locking, FCM guard policy, scope boundaries and Box anti-loop regression in CI.

Install/reinstall in Magisk; reboot. Do not enable the deprecated HyperGreeze LSPosed module unless separately validated on your firmware.
